# judith-inbox
Static web inbox (Hebrew, RTL) for approving replies to comments on The Judith's social accounts.
It reads and writes one Google Sheet via the Sheets API after Google sign-in (token kept in memory only).
This public repo contains no data and no secrets: only index.html, app.js, style.css.
Demo mode with fake rows and no network calls: open `index.html?demo=1`.
Served by GitHub Pages at https://baritzy.github.io/judith-inbox/
